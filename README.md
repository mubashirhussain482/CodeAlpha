# **🚀 CODEALPHA – JAVA PROGRAMMING INTERNSHIP**

---

## **📌 Repository Overview**

This repository contains the Java development internship projects completed as part of the **CodeAlpha Java Programming Internship**.

The projects demonstrate practical implementation of **Java programming, Object-Oriented Programming (OOP), GUI development, database connectivity, input validation, and software development concepts**.

Each project is organized in a separate folder for easy access and evaluation.

---

## **✅ Completed Projects**

### **📈 Stock Trading Platform**

A Java-based stock trading simulation that allows users to interact with market data and manage their investment portfolio.

**✨ Features:**

* Display available stock market data
* Buy and sell stocks
* Manage user portfolios
* Track balances and holdings
* Calculate portfolio performance
* Apply input validation
* Use Object-Oriented Programming (OOP) concepts

**🛠️ Technologies:**

* Java
* Object-Oriented Programming

---

### **🤖 Artificial Intelligence Chatbot**

A Java-based rule-driven chatbot designed for interactive communication with users.

**✨ Features:**

* Interactive text-based communication
* Greeting and conversational responses
* Frequently asked questions handling
* Rule-based response generation
* Basic Natural Language Processing (NLP) techniques
* Input cleaning and processing
* Real-time interaction through the console

**🛠️ Technologies:**

* Java
* Object-Oriented Programming
* Rule-Based NLP

---

### **🏨 Hotel Reservation System**

A Java-based hotel reservation system designed to manage hotel rooms, reservations, cancellations, and booking information.

**✨ Features:**

* Search and view available hotel rooms
* Categorize rooms by type
* Support Standard, Deluxe, and Suite rooms
* Make hotel reservations
* Cancel reservations
* View booking details
* Simulate payment processing
* Validate user input
* Manage room availability
* Store and manage booking information
* Apply Object-Oriented Programming (OOP) concepts

**🛠️ Technologies:**

* Java
* Object-Oriented Programming
* Database/File I/O Concepts
